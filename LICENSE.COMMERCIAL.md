# Коммерческая лицензия ISOTOPE

## Общие положения

Данный документ описывает условия коммерческого использования программного обеспечения ISOTOPE ("Программа").

Исключительные права на Программу принадлежат Владельцу — Petr Stepanov (isotope.network).

## Основная лицензия

Ядро ISOTOPE распространяется под GNU Affero General Public License v3 (AGPL v3).

Это означает, что любое использование Программы, её модификация и распространение должны соответствовать условиям AGPL v3, включая обязанность открывать исходный код производных работ при предоставлении доступа к ним по сети.

## Коммерческая лицензия

Для организаций и частных лиц, которые хотят использовать ISOTOPE в коммерческих целях без выполнения условий AGPL v3 (в частности, без обязанности открывать исходный код своих модификаций), предоставляется коммерческая лицензия.

### Что даёт коммерческая лицензия

- Использование ISOTOPE в закрытых (proprietary) продуктах
- Отсутствие обязанности публиковать исходный код модификаций
- Приоритетная поддержка
- Доступ к коммерческим модулям (ISOTOPE Enterprise)
- Сертификация и аудит безопасности

### Условия получения

Коммерческая лицензия предоставляется на основании отдельного лицензионного договора с Владельцем.

Для получения условий и стоимости:
- Email: commercial@isotope.network
- Сайт: https://isotope.network

### Срок действия

Коммерческая лицензия предоставляется на определенный срок (обычно 1 год) с возможностью продления.

### Ограничения

Коммерческая лицензия не даёт права:
- Сублицензировать Программу третьим лицам без согласия Владельца
- Использовать товарный знак ISOTOPE без разрешения
- Выдавать модифицированную версию за оригинальный ISOTOPE

## ISOTOPE Enterprise

ISOTOPE Enterprise — это коммерческий модуль для B2B-обмена данными между организациями (банки, страховые компании, медицинские учреждения).

Включает:
- Приватные подсети
- Дифференцированные права доступа
- Аудит-трейл
- Zero-Knowledge Proofs (в разработке)
- Интеграцию с корпоративными системами

ISOTOPE Enterprise доступен только по коммерческой лицензии.
