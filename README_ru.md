# ISOTOPE — Иммунная Система Открытого Прозрачного Пирингового Обмена

**Связь, которую нельзя заблокировать, отследить или уничтожить.**

ISOTOPE — децентрализованный P2P-мессенджер с этическим иммунитетом, анонимной маршрутизацией и адаптивной маскировкой трафика.

---

## Возможности

- **P2P без серверов** — невозможно заблокировать или отключить
- **Этический иммунитет** — нейросеть фильтрует насилие и спам автоматически
- **Onion Routing** — анонимность на собственных пирах, без Tor
- **Адаптивная маскировка** — трафик неотличим от обычного HTTPS
- **Взвешенная память** — важные данные живут, мусор затухает
- **Самоадаптация** — сеть корректирует параметры под нагрузку
- **E2E-шифрование** — никто не читает сообщения, кроме получателя
- **Работа без интернета** — mDNS, Bluetooth mesh, Wi-Fi Direct
- **Обход блокировок** — PWA, F-Droid, прямая загрузка APK

---

## Области применения

ISOTOPE — это не только мессенджер. Это протокол для любых взаимодействий, где нужны децентрализация, этическая фильтрация и экономика доверия.

| Домен | Применение |
|-------|------------|
| Мировая экономика | Трансграничные платежи без SWIFT, децентрализованный рынок данных, кредитный скоринг |

| Технологии | IoT без облака, федеративное обучение ИИ, P2P-DNS без корневых серверов |

## Быстрый старт

### Требования
- Docker и Docker Compose
- Go 1.21+ (для сборки из исходников)
- Flutter 3.x (для мобильного приложения)

### Запуск узла

    git clone https://github.com/isotope-network/isotope-core.git
    cd isotope-core
    docker compose build --no-cache
    docker compose up -d

Узлы:
- http://localhost:8081 (узел 1)
- http://localhost:8082 (узел 2)
- http://localhost:8083 (узел 3)

### Мобильное приложение

    cd mobile
    flutter pub get
    flutter run

## Как это работает

- **Этический хеш** — цифровое ДНК сети на основе семи заповедей
- **Нейросеть** — 100-мерные векторы сравнивают сообщения с эталоном
- **Коллективное обучение** — лайки/дизлайки учат сеть отличать добро от зла
- **Взвешенная память** — важное живёт дольше, спам затухает и удаляется
- **Onion Routing** — три случайных пира образуют анонимную цепочку
- **Самоадаптация** — сеть собирает метрики и корректирует параметры
