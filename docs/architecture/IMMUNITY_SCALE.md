# Immunity Scale

## Important Distinction

ISOTOPE operates on two levels:

| Level | What Works | Minimum Nodes |
|-------|-----------|---------------|
| **Protocol** | Query-response, encryption, P2P transmission | 2-3 |
| **Immunity** | Response weighting, lie detection, self-purification | 15-20+ |

Below 15 nodes, ISOTOPE is a secure P2P protocol.
Above 15 nodes, the immune system activates.

---

## How Immunity Works at Different Scales

### 2-3 Nodes: Communication Channel
- Query-response works
- Encryption works
- No immunity
- If the only responding node lies, the recipient won't know

### 5-10 Nodes: Early Consensus
- Statistics emerge: multiple responses to one query
- Outliers become visible (one node responds differently)
- Node weights are still unstable — insufficient data for reputation

### 15-20 Nodes: Immunity Activates
- Node weights begin to reflect real reputation
- False responses systematically fade
- Honest nodes accumulate weight
- Consensus is reached automatically

### 50+ Nodes: Stable Immunity
- High weighting accuracy
- Collusion of several nodes does not affect the result
- Ethical filter operates at full capacity

### 100+ Nodes: Unstoppable Network
- Node replacement does not affect the network (self-healing)
- DHT ensures global connectivity
- Even 30% malicious nodes cannot distort consensus

## What This Means for the E0 Pilot

Pilot project: 3 banks + 1 insurer = **4 nodes**.

At 4 nodes:
- Protocol query-response works
- Encryption works
- Anonymization works
- Immune system does **not** work — this is a protocol demonstration, not immunity

Immunity activates when the consortium grows to 15+ organizations.

---

## Why This Is Honest

ISOTOPE does not promise immunity at 3 nodes. That would be a lie.

ISOTOPE honestly states:
- At 2-3 nodes: secure channel
- At 15+ nodes: immune system
- At 100+ nodes: unstoppable network

Scale activates immunity. This is an architectural property, not a flaw.
