# Этический движок ISOTOPE

## Обзор

Этический движок — это нейросеть,
которая оценивает каждое сообщение
на соответствие этическому хешу сети.

Это не цензура. Это иммунная система.

Этика ISOTOPE уже работает с сообщениями.
В будущем (v3.0+) она будет проверять и ИИ-модели:
до загрузки на узел модель получит этический паспорт —
хеш от архитектуры и тренировочных данных.
Это нужно, чтобы вредная модель не попала в сеть.
Подробнее — в концепции ISOTOPE AI Mesh.

---

## Этический хеш

### Что это

Этический хеш — цифровое ДНК сети.
Строка, преобразованная в 100-мерный вектор через SHA-256.

Текущий хеш основан на семи универсальных заповедях:

    Не причиняй вреда.
    Не кради.
    Не обманывай.
    Не предавай.
    Не будь равнодушным.
    Созидай, а не разрушай.
    Относись к другим как к себе.

Эти принципы собраны из всех великих учений человечества.
Они не принадлежат ни одной религии, ни одной идеологии.

### Как работает

1. Строка заповедей хешируется в SHA-256 → `hashText()`
2. Хеш преобразуется в 100-мерный вектор → `hashToVector()`
3. Вектор эталона сравнивается с вектором каждого сообщения
   → `cosineSimilarity()`
4. Начальный вес сообщения = `0.3 + близость × 0.5`

## Этическое пространство ISOTOPE

### Межсетевая совместимость

Разные языковые сети (ISOTOPE-RU, ISOTOPE-EN, ISOTOPE-DE)
связаны не мостами перевода, а этическим пространством.

Каждая сеть публикует свой этический вектор —
смысловую проекцию семи заповедей.
Сети сравнивают векторы через косинусное сходство.

Порог совместимости: **> 0.7** (адаптивно повышается).

Совместимость не означает перевод. Она означает доверие.
Сообщения между сетями проходят только если их векторы близки.

### Как это работает технически

1. Сеть A вычисляет вектор своего этического хеша
2. Сеть B вычисляет вектор своего этического хеша
3. Узлы сравнивают векторы через `cosineSimilarity()`
4. Если сходство > 0.7 — сети совместимы, обмен разрешён
5. Если нет — соединение не устанавливается

Перевод (если нужен) выполняется локально
на устройстве получателя.
Векторы решают задачу доверия, а не перевода.

## Нейросеть

### Архитектура

- **Размерность:** 100 нейронов на слой (VectorDim = 100)
- **Слои:** растут каждые 20 сообщений
- **Активация:** ограничение от -1 до 1
- **Обучение:** градиентный спуск по последнему слою

### Forward

    inputVector (100 чисел) → слой 1 → слой 2 → ... → outputVector

Каждый слой умножает вектор на свои веса
и ограничивает значения.

### Train

    ошибка = target - output
    веса += ошибка × learningRate
    learningRate = 0.01 × вес_сообщения

## Векторизация текста

### textToVector

Преобразует текст в 100-мерный вектор:

1. **30%** — отдельные символы:
   коды букв распределяются по 100 измерениям
2. **70%** — биграммы:
   пары символов хешируются в SHA-256 и распределяются
3. **Нормализация** — деление на максимум

### Почему биграммы

«убей» → `уб`, `бе`, `ей`
«помогите» → `по`, `ом`, `мо`, `ог`, `ги`, `ит`, `те`

Разные биграммы → разные векторы → сеть различает смысл.

## Коллективное обучение

### Лайк

- Вес сообщения: +0.15
- Обучение нейросети: `train(input, output, ethicsVec, lr)`
  — тянет к эталону
- При 5 лайках: вес = 1.0, обучение усилено

### Дизлайк

- Вес сообщения: -0.15
- Обучение нейросети: `train(input, output, invertedInput, lr)`
  — отталкивает от эталона
- При 4 дизлайках: вес < 0.15 → архивация

## Персональные фильтры

### preHash

Пользователь вводит слова, которые хочет видеть.
Вектор preHash притягивает сообщения с похожим смыслом.

Формула: `weight = ethicsScore × 0.4 + preSimilarity × 0.6`

### antiHash

Пользователь вводит слова, которые не хочет видеть.
Вектор antiHash отталкивает нежелательные сообщения.

Формула: `weight = weight × (1 - antiSimilarity × 0.8)`

---

## Жизненный цикл сообщения

    Новое сообщение
    → Этическая близость (хеш)
    → preHash (притяжение)
    → antiHash (отталкивание)
    → Итоговый вес
    → Лайки/дизлайки (обучение)
    → Старение (-0.01/час)
    → Вес < 0.15 → архивация
    → Вес < 0.1 → удаление

---

## Ограничения

- **100 измерений** — хорошо для коротких фраз,
  но не для семантического анализа
- **Биграммы** — различают слова, но не контекст
- **Коллективное обучение** — требует тысяч оценок
  для заметного эффекта
- **preHash/antiHash** — конфликтуют на коротких словах
