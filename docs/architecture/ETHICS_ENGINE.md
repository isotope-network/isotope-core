# Этический движок ISOTOPE

## Обзор

Этический движок — это нейросеть, которая оценивает каждое сообщение на соответствие этическому хешу сети.

Это не цензура. Это иммунная система.

---

## Этический хеш

### Что это

Этический хеш — цифровое ДНК сети. Строка, преобразованная в 100-мерный вектор через SHA-256.

Текущий хеш основан на семи заповедях:

    Не убий. Не укради. Не лги. Не предавай. Помогай. Созидай. Уважай.

### Как работает

1. Строка заповедей хешируется в SHA-256 → `hashText()`
2. Хеш преобразуется в 100-мерный вектор → `hashToVector()`
3. Вектор эталона сравнивается с вектором каждого сообщения → `cosineSimilarity()`
4. Начальный вес сообщения = `0.3 + близость × 0.5`

---

## Нейросеть

### Архитектура

- **Размерность:** 100 нейронов на слой (VectorDim = 100)
- **Слои:** растут каждые 20 сообщений
- **Активация:** ограничение от -1 до 1
- **Обучение:** градиентный спуск по последнему слою

### Forward

    inputVector (100 чисел) → слой 1 → слой 2 → ... → outputVector

Каждый слой умножает вектор на свои веса и ограничивает значения.

### Train

    ошибка = target - output
    веса += ошибка × learningRate
    learningRate = 0.01 × вес_сообщения

---

## Векторизация текста

### textToVector

Преобразует текст в 100-мерный вектор:

1. **30%** — отдельные символы: коды букв распределяются по 100 измерениям
2. **70%** — биграммы: пары символов хешируются в SHA-256 и распределяются
3. **Нормализация** — деление на максимум

### Почему биграммы

«убей» → `уб`, `бе`, `ей`
«помогите» → `по`, `ом`, `мо`, `ог`, `ги`, `ит`, `те`

Разные биграммы → разные векторы → сеть различает смысл.

## Коллективное обучение

### Лайк

- Вес сообщения: +0.15
- Обучение нейросети: `train(input, output, ethicsVec, lr)` — тянет к эталону
- При 5 лайках: вес = 1.0, обучение усилено

### Дизлайк

- Вес сообщения: -0.15
- Обучение нейросети: `train(input, output, invertedInput, lr)` — отталкивает от эталона
- При 4 дизлайках: вес < 0.15 → архивация

---

## Персональные фильтры

### preHash

Пользователь вводит слова, которые хочет видеть. Вектор preHash притягивает сообщения с похожим смыслом.

Формула: `weight = ethicsScore × 0.4 + preSimilarity × 0.6`

### antiHash

Пользователь вводит слова, которые не хочет видеть. Вектор antiHash отталкивает нежелательные сообщения.

Формула: `weight = weight × (1 - antiSimilarity × 0.8)`

---

## Жизненный цикл сообщения

    Новое сообщение
    → Этическая близость (хеш)
    → preHash (притяжение)
    → antiHash (отталкивание)
    → Итоговый вес
    → Лайки/дизлайки (обучение)
    → Старение (-0.01/час)
    → Вес < 0.15 → архивация
    → Вес < 0.1 → удаление

---

## Ограничения

- **100 измерений** — хорошо для коротких фраз, но не для семантического анализа
- **Биграммы** — различают слова, но не контекст
- **Коллективное обучение** — требует тысяч оценок для заметного эффекта
- **preHash/antiHash** — конфликтуют на коротких словах
